  COINGECKO API KEY SETUP - DATABRICKS SECRETS
═══════════════════════════════════════════════════════════════════════════

Follow these steps to securely add your CoinGecko API key to Databricks:

─────────────────────────────────────────────────────────────────────────
  OPTION 1: Using Databricks CLI (Recommended)
─────────────────────────────────────────────────────────────────────────

1. Install Databricks CLI (if not already installed):

   pip install databricks-cli

2. Configure authentication:

   databricks configure --token

   Enter workspace URL: https://<your-workspace-url>.azuredatabricks.net/
   Enter your personal access token when prompted

3. Create a secret scope:

   databricks secrets create-scope coingecko

4. Add your CoinGecko API key:

   databricks secrets put-secret coingecko api_key

   This opens an editor. Paste your API key, save, and close.

5. Verify the secret was created:

   databricks secrets list-secrets coingecko

─────────────────────────────────────────────────────────────────────────
  OPTION 2: Using Databricks Workspace UI
─────────────────────────────────────────────────────────────────────────

1. Navigate to your workspace:
   https://<your-workspace-url>.azuredatabricks.net/

2. In the left sidebar, click "Settings" (gear icon)

3. Click "User Settings"

4. Go to "Developer" tab

5. Under "Access tokens", click "Manage" next to "Secret Scopes"
   OR directly navigate to:
   https://<your-workspace-url>.azuredatabricks.net/#secrets/createScope

6. Create a new scope:
   - Scope name: coingecko
   - Manage Principal: Creator
   - Click "Create"

7. Add a secret:
   - In the scope "coingecko", click "Add Secret"
   - Key: api_key
   - Value: [paste your CoinGecko API key]
   - Click "Add Secret"

─────────────────────────────────────────────────────────────────────────
  VERIFICATION
─────────────────────────────────────────────────────────────────────────

Test your secret reference:

  databricks secrets get coingecko api_key

You should see: [REDACTED] (secrets are never displayed in plaintext)

─────────────────────────────────────────────────────────────────────────
  GETTING YOUR COINGECKO API KEY
─────────────────────────────────────────────────────────────────────────

If you don't have a CoinGecko API key yet:

1. Go to: https://www.coingecko.com/en/api

2. Click "Get Your Free API Key"

3. Sign up or log in

4. Copy your API key from the dashboard

Note: Free tier has 30 calls/min rate limit

═══════════════════════════════════════════════════════════════════════════

The MCP server will automatically read the secret from:
  {{secrets/coingecko/api_key}}

This is already configured in src/app.yaml
